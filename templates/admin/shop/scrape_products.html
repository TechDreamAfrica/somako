How to Use the Real Scraper:

To scrape real products from AliExpress using the command line:


# Scrape products with keyword search
python manage.py scrape_aliexpress --keyword "phone accessories" --count 10

# Use mock mode (current admin interface uses this)
python manage.py scrape_aliexpress --mock --count 15

# Specify a category
python manage.py scrape_aliexpress --mock --count 10 --category electronics

# Import from CSV file
python manage.py import_products --file products.csv --format csv
