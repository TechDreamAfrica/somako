# APK File Directory

Place your Soma Ko Android APK file in this directory.

## Instructions:
1. Build your Android APK file
2. Name it `soma-ko-app.apk` (or update the filename in core/views.py)
3. Place it in this directory: `static/apk/soma-ko-app.apk`

The downloads page will automatically serve this file for download.

## Current Settings:
- Default APK filename: `soma-ko-app.apk`
- Download URL: `/downloads/`
- Static path: `static/apk/soma-ko-app.apk`

To change the APK filename, update the `apk_filename` variable in `core/views.py`.
